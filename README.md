#### 📕Our work (강조해야 될 포인트는 뭘까?)
##### Design
* AI 툴을 활용하여 노래의 분위기와 어울리는 시를 창작하였습니다
<br> 예시)
<br>지난날의 그 맑은 마음은
<br>지금도 별빛이 되어
<br>내 하늘 한쪽에서
<br>조용히 빛나고 있다
<br>-권용준, 「별」 중
* AI 툴을 활용하여 메인 페이지에 사계절에 어울리는 명화를 생성하였습니다
<br>프롬트 예시)
<br>겨울에 대한 이미지를 생성하고 싶어. 침엽수가 꼭 들어갔으면 좋겠어. 인상주의 화풍으로 그려줘. 사람과 건물 없이 그려. 세로 이미지로 생성.
