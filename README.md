### Our work 

#### Design: 전체 디자인 컨셉은 '영화 필름'입니다. 색은 계절감을 드러내도록, 위치는 보기에 깔끔하도록 디자인하였습니다

<메인 페이지>

* 메인 페이지 전체를 직접 코드를 짜서 구현하였습니다
<br> ex) 첫 페이지 상단 평행사변형의 위치를 고정하는 방식으로 삽입하였습니다. 즉, 사용자의 화면에 맞춰서 비율이 조절될 수 있도록 맞췄습니다.
<br> ex) 메인 페이지와 세부 페이지를 왔다갔다하는 메커니즘, 즉 여러개의 독립된 html을 한 사이트 내에서 이동하는 방식을 구현하였습니다.

* 두 페이지에 그라데이션 효과 및 애니메이션을 추가하였습니다
* 첫 페이지 Opso 타이틀 우측 하단에 한양대학교 로고를 삽입하였습니다  
* 아래 페이지의 세로 분할은 직접 CSS와 HTML을 통해 구현하였습니다

<AI 이용>

*코드 
* AI 툴을 활용하여 메인 페이지에 사계절에 어울리는 명화를 생성하였습니다
<br>프롬프트 예시)
<br>겨울에 대한 이미지를 생성하고 싶어. 침엽수가 꼭 들어갔으면 좋겠어. 인상주의 화풍으로 그려. 사람과 건물 없이 그려. 세로 이미지로 생성

<세부 페이지>

* 재생 버튼을 누르면 사이트에서 노래가 재생되는 매커니즘을 구현하였습니다
* 세부 페이의 CSS framework로 tailwind 디자인 프로그램을 사용하였습니다
* 각 요소의 위치, 컬러, 애니메이션, 도형 디자인 등의 세부 디자인은 모두 직접 구현하였습니다
